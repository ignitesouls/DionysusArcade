# Dionysus Arcade

<p align="center"><img src="src/Dionysus.App/Assets/dionysus_256.png" width="128" alt="Dionysus Arcade logo"></p>

Dionysus Arcade is an Elden Ring modding app for playing a growing collection of game modes, each one infinitely customizable. It began as an offshoot of the [Athena Randomizer](https://github.com/ignitesouls/AthenaRandomizer), built to host the Cluedo, Battleship and Legacy-Locked game modes, and was rebuilt from the ground up as its vision grew. Athena and Dionysus are both the combined work of Team Ignite's community leaders.

## Features

- **Modes:** one-click modes such as Classic Battleship, Battleship Boss Shuffle and Classic Cluedo, plus your own saved profiles.
- **Custom:** start from any mode, change anything, and save the result as a profile.
- **Seeds:** the same seed and settings always produce the same game within a version.
- **Elden Ring Item and Enemy Randomizer:** optional play through Matt's randomizer, with boss arenas shuffled by the Boss Arena Randomizer.

## Playing

1. Download the latest version from [Releases](../../releases).
2. Extract it somewhere like Documents or the Desktop. Avoid Program Files, because Dionysus writes its mod files inside its own folder.
3. Run `Dionysus Arcade.exe`, pick a mode, click **Assemble**, then **Launch Elden Ring**.
